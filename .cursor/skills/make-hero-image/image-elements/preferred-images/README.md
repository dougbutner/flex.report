# Preferred images (user only)

Drop PNG (or WebP) files here for the hero composer to use.

- **You** add / rename / delete files in this folder.
- The agent may **read** files here when composing heroes.
- The agent must **never** create, edit, overwrite, or delete files here.

Name files simply so they resolve as icons, e.g. `breath-photo.png` → `--icons breath-photo`.
