## Provide liquidity

Prefer **1% fee** EASY pools. Higher fee on busy books feeds Welcome, Club, and MEME buybacks.

Example (moves with volume): [EASY/XPR](https://alcor.exchange/v/xpr/analytics/pools/4512) · 1% fee · recent ≈14% fee APY (≈$890/day on ≈$24k TVL).

Check [Alcor Farms](https://alcor.exchange/v/xpr/analytics?tab=farms) before you size.

If you LP, **opt out of tax on that account first**. Opt-out is one-way on that wallet. Use a second account if you still want reflections.

No LP capital? **100 EASY** is enough to earn reflections when anyone hits Send It.

## Opt out of tax

Flex Tools → Opt out of tax. Removes the **2%** tax on that account. You also drop reflection rewards on that account forever.

## Welcome Program

![Welcome Program on flex.town](assets/flextown/welcome.png)

Contract [`invite.mon3y`](https://explorer.xprnetwork.org/account/invite.mon3y). Bank [`inbank.mon3y`](https://explorer.xprnetwork.org/account/inbank.mon3y). UI: flex.town → Welcome.

Request a welcome (`ask4invite`). Someone later pays **200 EASY**: **100 to you**, **100 to the vault**. Vault yield splits among the tree.

Once welcomed, welcome the next person. Grow the tree. Claim forever.

| Flow | On flex.town |
| --- | --- |
| Ask to be welcomed | Welcome → Request a welcome |
| Welcome an account | Welcome → send 200 EASY package |
| Share links | Welcome → Telegram / WhatsApp / X / email / text |
| View network | Welcome → View welcome network |

**38.2%** of EASY-side pool fees fund `invite.mon3y`.
