1. Get a [WebAuth](https://webauth.com) wallet. Fund it with XPR or USD(c).

3. Hold **100+ EASY** so reflections pay you. On [flex.town](https://flex.town): set your reward token, send rewards, name a beneficiary, request a Welcome invite.
4. Keep the bag. Tell one person.

Bookmark [flex.town](https://flex.town).
